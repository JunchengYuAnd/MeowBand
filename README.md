# MeowBand · 小猫的四人乐队

给 iPad 和小猫设计的离线音乐捕猎游戏。四个游戏分别让小猫控制节奏、和声 Pad、低音、旋律；其余声部持续伴奏。

## 四个游戏

| 游戏 | 捕猎玩法 | 拍中后的音乐作用 |
| --- | --- | --- |
| 节奏捕猎 | 4 只小虾、飞蛾，停顿与冲刺交替 | 立即敲击，逐渐突出鼓与轻打击乐 |
| 和声涟漪 | 2 条较大的鱼，缓慢游动 | 立即展开和弦，下一个双小节边界改变和声色彩 |
| 低音追踪 | 1 条大鱼，在屏幕下部游动 | 立即拨动低音，让低音声部突出 |
| 旋律追光 | 3 条轻快游鱼 | 立即弹出单音，下一个双小节边界变化旋律动机 |

## 连贯编曲

- 共用 72 BPM 时钟，两小节短句、四小节乐句、十二小节和声段落循环。
- 拍击立即回应，不重置音乐时钟；声部突出程度在拍点调整。
- 最近的拍击记录带有衰减，影响声部分工和编曲密度。
- 旋律选音兼顾动机、上一音、和弦内音与句末收束。
- Pad 通过寻找邻近和弦排列减少声部跳跃；鼓和低音共享重拍。
- 音符数量和并发声音受限，长时间无互动会完成乐句、回到主和弦并安静下来。
- 暂停会同步停止声音；同一游戏恢复时保留音乐位置，切换游戏则开始新一轮编曲。
- 退到后台或发生系统音频中断时进入主人设置，需要手动继续。

## 其他功能

多点触控、命中水花、扑空惊动附近猎物、动态捕猎难度、计时与结算。游戏画面不显示 HUD，双指按住 2 秒打开设置。可调整猎物速度、尺寸及 2 / 3 / 5 分钟时长，并选择高对比夜池或黑白极简画面。

捕猎通过 `Notification.Name.meowBandCatch` 发布位置、速度、当前声部、得分和时间戳。MIDI / OSC 尚未接入。

## 运行与验证

使用 Xcode 打开 `MeowBand.xcodeproj`，选择 iPad 模拟器或真机运行。要求 iPadOS 17+。真机运行需要设置开发团队。

音乐逻辑测试不依赖模拟器：

```sh
swiftc MeowBand/EnsembleConductor.swift Tests/main.swift -o /tmp/meowband-music-tests
/tmp/meowband-music-tests
```

`Tests/AudioSmoke.swift` 用于在已启动的 iOS 模拟器里验证四声部音频启动、触发、暂停、恢复和停止；编译时与 `EnsembleConductor.swift`、`EnsembleAudio.swift` 一起使用模拟器 SDK。声音使用本地生成并缓存的 PCM，不依赖音频下载。

## 代码

- `ContentView.swift`：四个游戏入口、设置、计时、计分与结算。
- `FishGameScene.swift`：四种捕猎参数、猎物行为、触控与特效。
- `EnsembleConductor.swift`：可独立测试的音乐决策与编曲时钟。
- `EnsembleAudio.swift`：PCM 合成、声音池、硬件时钟调度与播放生命周期。

水下背景及猎物图片位于 `MeowBand/Assets.xcassets`。音色仍为合成版本，真机扬声器上的低音听感和触控反馈需要继续体验校准。
