# MeowBand · 小猫的海底乐园

专为 iPad 和小猫设计的原生多点触控捕猎鼓组。小猫抓中不同猎物时，会演奏不同的鼓声。

## 当前玩法

- 默认同时出现 4 个猎物，每个都有独立的观察、停顿、冲刺、躲藏和探头节奏
- 默认鼓组包含底鼓、军鼓、踩镲和嗵鼓，飞蛾会偶发触发镲片
- 鼓声由预生成的打击乐缓存播放，支持多点触控与声音叠加
- 小鱼、小虾和飞蛾三种猎物，可调节速度、尺寸与游戏时长
- 猎物在移动中持续独立加速和减速，不会以固定速度同步游动
- 扑空会惊动触点附近的猎物；扑中后对应猎物挣扎、水花爆开并由新猎物替补
- 游戏会根据连续抓中或扑空动态调节猎物难度
- 18 秒无互动时，猎物会抖动并发声重新吸引注意
- 游戏画面不显示 HUD；双指按住 2 秒进入主人设置
- 支持多点触控、触觉反馈、结算和重新开始
- 每次抓鱼通过 `Notification.Name.meowBandCatch` 发布位置、鱼种、速度、得分和时间戳，可继续连接 MIDI、OSC 或音乐引擎

## 运行

1. 使用 Xcode 打开 `MeowBand.xcodeproj`
2. 选择 iPad 模拟器或已连接的 iPad
3. 真机运行前，在项目 Signing & Capabilities 中选择自己的开发团队
4. 点击 Run

要求 iPadOS 17 或更高版本。

## 视觉素材

水下背景、六个鱼类角色、小虾和飞蛾使用 OpenAI 内置图像生成工具制作，经过透明背景处理后存放在 `MeowBand/Assets.xcassets`。游戏运行不依赖网络。
